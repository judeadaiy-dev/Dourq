# TeamHub

موقع إدارة فريق متكامل: Next.js (App Router) + Tailwind + Supabase، بواجهة عربية واتجاه RTL ولوحة ألوان أوف وايت وبني هادئة.

## الصفحات
- `/login` `/signup` تسجيل الدخول وإنشاء حساب — `/onboarding` إكمال الملف الشخصي — `/account` إعدادات الحساب (الصورة، التخصص، الخبرة، السيرة الذاتية، البريد وكلمة المرور)
- `/workspace` التواجد الحي — `/chat` قنوات محادثة ورسائل صوتية ومرفقات وإشارات للأعضاء
- `/tasks` لوحة كانبان بإسناد وأولويات ومواعيد وتعليقات ومرفقات — `/people` دليل الفريق والبحث والتخصصات والتوفر
- مركز إشعارات لإسناد المهام والإشارات وتغييرات الحالة

## التشغيل
1. أنشئ حساب المالك بالبريد المحدد في الدالة `th_ensure_profile` وأكّد البريد الإلكتروني. لا تعطّل تأكيد البريد؛ صلاحية المالك مخصصة لهذا البريد المؤكد، والعضويات الجديدة تحتاج موافقته.
2. خذ نسخة احتياطية من قاعدة البيانات، ثم شغّل `supabase/schema.sql` كاملاً في Supabase > SQL Editor. يتضمن ذلك جدول `th_notifications` وسياساته ومشغّلات إنشاء الإشعارات، ويحدّث سياسات الجداول ومخازن الصور والمرفقات الخاصة، ثم يعيد تحميل مخطط PostgREST.
3. سجّل الدخول إلى التطبيق بهذا الحساب. الحسابات التي أنشئت قبل تشغيل المخطط تحتاج تسجيل الدخول مجدداً لإنشاء ملفها الشخصي.
4. `npm install` ثم `npm run dev` وافتح http://localhost:3000
5. للنشر (Netlify/Vercel) أضف المتغيرين في `.env.example` كمتغيرات بيئة.

## الخصوصية
المحادثات ومرفقاتها وصور الحساب والسير الذاتية تتطلب عضوية معتمدة وروابط تنزيل مؤقتة. السيرة الذاتية PDF خاصة ولا تظهر إلا لأعضاء الفريق المعتمدين. رسائل الصوت تُسجّل على جهاز المستخدم وتُرسل مع مخطط الترددات المقاس، ولا يوجد اتصال صوتي مباشر. حذف الرسالة مسموح لمرسلها أو لمالك المساحة.

يلزم تشغيل مخطط Supabase قبل استخدام ميزات التخزين الجديدة. البناء المحلي لا يختبر سياسات قاعدة البيانات؛ اختبرها في مشروع Supabase قبل نشر بيانات حقيقية.
